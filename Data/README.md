# Data catalog

Open formats only (JSON, JSON Lines, SQLite, Markdown, plain text). Every record is id-addressed: sources `SRC-######`, claims `CLM-######`, strategy bets `BET-##`, assumptions `ASM-###`, roadmap milestones `RM-###`. The web page and the web app are generated from these files; nothing in them is hand-typed.

| Folder | Format | Contents | Used by |
|---|---|---|---|

## Asking an AI about this data

Point the assistant at `registries\claims_registry.jsonl` for facts (each line is a self-contained claim with its sources), `reports\` for the narrative, and `strategy\data\` for the plan. The kind labels (FACT, INTERPRETATION, HYPOTHESIS, SCENARIO, RECOMMENDATION, ASSUMPTION) and the `status` field (SUPPORTED, PARTIALLY_SUPPORTED, INCONCLUSIVE, …) travel with every record; keep them when quoting.
