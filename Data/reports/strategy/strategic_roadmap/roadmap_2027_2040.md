# Roadmap 2027-2040 (A11c v2, wave 6)

**Version v2** (A11c-bis, 2026-11-21). RM ids are kept from v1 so council references stay valid; new milestones are RM-051 to RM-054. Moved: RM-012 (2027 H1), RM-026 (2028 H1), RM-031 (2028 H2).

Research cutoff 2026-11-21. Milestones are by half-year where an external date or a gate makes that meaningful; later years are coarser. Basis `evidence` means the date comes from a registry claim; `ASSUMPTION` means the timing is a planning assumption. Dependencies use RM ids from `strategy/data/roadmap.json`.

## Phases

- **Foundations and validation (2027-2028).** Close IVB-001, IVB-003, IVB-004 and IVB-006 questions; set baselines; start BET-01 thin slice, BET-09 rented pilot, BET-17 measurement; prepare Entyvio posture for January 2028 [CLM-007026]; benefit-channel gate 2027 H1; plasma-peer and additionality gates 2027 H2.
- **Pilots and first gates (2028-2029).** Plasma one-site pilot, Nabla and Iambic go/no-go, launch-pathway pilot, first option deals. H1 portfolio review in 2029 H2.
- **Scale decisions and the Entyvio window (2029-2032).** Plasma roll-out decision, biosimilar-event playbook live, option exercise, earliest possible biosimilar window (stress case S-A, 2028-2029; ASM-025 range 2028-2032, central 2031) and 2032 patents [CLM-005017].
- **Compounding or exit (2033-2040).** Orexin second-asset readouts, conversion check on options, persistence of device users, 2040 value review. External anchors: tirzepatide patent to 2036 and Rinvoq entry not before April 2037 test competitor concentration and settlement-based defence [CLM-000250] [CLM-003021].

## Dependency chains *(INTERPRETATION)*

1. **Measurement chain:** inventory and baselines (BET-17) -> thin-slice data standard (BET-01) -> rented pilot data (BET-09) -> AI-design benchmarking (BET-07) -> AI-scale gate. A break at any link stops downstream spend.
2. **Plasma chain:** baseline and demand-versus-capacity test (IVB-006) -> plasma-peer gate -> one-site shadow-mode run -> scale decision -> roll-out -> neutral analytics decision.
3. **Entyvio chain:** benefit-channel gate (2027 H1) -> January 2028 posture -> playbook live (2028 H1) -> earliest window -> 2032 patents. This chain has fixed dates and cannot be postponed.
4. **Pipeline chain:** zasocitinib action and PsA -> launch curves -> BET-18 trigger review; orexin plan -> second-asset first-in-human -> Phase 2 -> platform test.
5. **Option chain:** scorecard -> first deals -> exercise on Phase 1/2 data -> approvals conversion check.
