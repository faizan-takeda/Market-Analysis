## Which file answers which question
- "How did Lilly / J&J / AbbVie become successful and what is different about them?" → `deliverables/competitor_comparison.md`, then `New_mediciine/cross_company_analysis/master_comparison.md`, then the dossier.
- "What has each demonstrably achieved vs announced?" → company `successes_failures/`, `industry_transformation/pipeline_regulatory/fda_approvals_2022_2026.md`, `ai_data_robotics/maturity_matrix.md`.
- "What gives each a moat?" → company `competitive_advantage/moats.md`, `ai_data_robotics/capability_mechanism_cards.md`, `strategy/platform_moats/moat_mechanisms_taxonomy.md`.
- "What does Takeda already have?" → `companies/takeda_public_baseline/capability_baseline/capability_baseline.md` + `internal_validation_backlog/backlog.md`.
- "What should Takeda build / partner / invest / avoid?" → `deliverables/takeda_strategy.md` → `strategy/investment_theses/strategic_bets.md` (v2) → council files.
- "How much, when, and how to decide to scale?" → `deliverables/investment_roadmap.md` → `strategy/financial_cases/` → `strategy/data/portfolios.json`.
- "Why could we be wrong?" → `strategy/critical_challenges/counterarguments_and_uncertainty.md`, View 12 in the hub.
- "What is NOT known?" → `quality/final_validation.md` §4, every `evidence_gaps.md`, `coverage_summary.md`.

## Refreshing without losing history
Registries are append-only for statements; status/maturity/basis/corrections are amended only by the Director with an `audit_history` entry and a `conflicts.jsonl` record (`scripts/apply_audit*.py` are the templates). New research goes into a shard (`tools/evidence.py`), is merged with `python3 scripts/merge_shards.py <shard>`, then `./launch.sh` rebuilds data, app and single file. Strategy numbers regenerate from `strategy/data/_a11c_*.py`. Commit with explicit paths.
